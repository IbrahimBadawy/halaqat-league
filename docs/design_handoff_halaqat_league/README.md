# Handoff: منصة دوري الحلقات — Halaqat League Platform

## Overview
تصميم كامل (40+ شاشة) لمنصة Mobile-first + PWA لإدارة دوريات كرة قدم مجتمعية: متابعة حية، تسجيل أحداث من الملعب، ترتيب وإحصائيات، كروت قوة، مجتمع، مسابقات، ولوحة أدمن ديسكتوب كاملة (معالج إنشاء، قرعة، مولد جدول، تشغيل يومي). البيانات التجريبية في التصميم هي بيانات الدوري الحقيقي الأول «دوري الحلقات — صيف 2026» (10 فرق، مجموعتان، 24 مباراة، 4 ليالي جمعة).

**اقرأ مع هذا الملف:** `league-platform-spec.md` (المواصفة الوظيفية الكاملة v1.1 — المرجع الأول للسلوك) و`prompt-claude-code.md` (عدة البناء المقترحة) — منسوخان في هذا المجلد.

## About the Design Files
`Halaqat League Design.dc.html` + `support.js` هما **مرجع تصميم مبني بـ HTML** (نموذج معاينة)، وليسا كودًا إنتاجيًا يُنسخ. المطلوب **إعادة بناء هذه الشاشات في بيئة المشروع**: Next.js 15 (React 19 + TypeScript) + Tailwind + shadcn/ui بدعم RTL + Supabase، كما تحدد المواصفة §8. افتح ملف التصميم في المتصفح للمعاينة (يحتاج `support.js` بجواره)؛ كل شاشة داخل إطار هاتف 390×844 أو إطار ديسكتوب 1180.

## Fidelity
**High-fidelity.** الألوان والخطوط والمسافات والحالات نهائية ومطابقة لهوية بوستر الدوري (`poster-reference.png` مرفق). أعد بناء الواجهات بدقة بكسل باستخدام مكونات المشروع.

### الخطوط (Google Fonts)
- **Changa** (800/700/600): عناوين، أرقام، نتائج. النتيجة الحية 44–48px، نتيجة TV 120px، عنوان شاشة 19–22px.
- **IBM Plex Sans Arabic** (400–700): نصوص. الحد الأدنى 12.5px للتسميات و14px للنص الأساسي.
- الأرقام لاتينية دائمًا داخل عزل LTR: `direction:ltr; unicode-bidi:isolate; font-variant-numeric:tabular-nums` (كلاس `.num` في التصميم).

### إيقاع ومكونات
- مسافات 8pt: 4/8/12/16/24/32/48. أنصاف أقطار: شريحة 10–13، بطاقة 14–16، ورقة سفلية 20–24 (علوي فقط)، حبة 999. هاتف 390×844 بحواف 44.
- أهداف لمس ≥44px (أزرار الكونسول 62–64px).
- ظلال: بطاقة `0 10px 30px rgba(0,0,0,.4)`، توهج ذهبي `0 0 24px rgba(224,178,74,.35)`، توهج مباشر `0 0 18px rgba(229,72,77,.5)`.
- درع الفريق: `clip-path: polygon(0 0,100% 0,100% 70%,50% 100%,0 70%)` بإطار ذهبي 2–3px حول درع أزرق يحمل الرمز (A1…B5) بخط Changa.
- «عدة الحيوية»: توهج ملعب أخضر radial أسفل الشاشة، توهج أزرق أعلى البطاقات البارزة، خطوط سرعة `repeating-linear-gradient(115deg, rgba(245,210,113,.05) 0 2px, transparent 2px 24px)`، وميض ذهبي متحرك على الأرقام الحية (keyframes `shim`: background-position 200%→−200%، ~3s linear infinite)، نبض شارة مباشر (`lp`: opacity 1→.25، 1.2s).
- هوية البوستر: تاج ذهبي فوق الشعار (clip-path polygon)، شريط شعار مائل skewX(−6deg) بتدرج ذهبي، الشعارات: «التحدي يبدأ .. والبطولة لنا» / «فريق واحد .. هدف واحد» / «شغف لا ينتهي» / «روح المنافسة».

## Screens / Views
كل الشاشات في `Halaqat League Design.dc.html` مقسمة أقسامًا (5 = الأحدث في الأعلى). المعرفات بادئة بالقسم:

**القسم 1 — النظام والحرِج:** 1a نظام التصميم الكامل · 1b الرئيسية (النسخة الأولى) · 1c صفحة المباراة الجارية (تبويبات: أحداث/تشكيلات/إحصائيات/مواجهات/تفاعل/معرض) · 1d كونسول التسجيل `/match/{id}/console` (3 مناطق: نتيجة+ساعة / لوحتا لاعبين / شريط 11 حدثًا — الأربعة الأكثر تكرارًا أزرار ثابتة كبيرة) · 1e تسجيل هدف بضغطتين + Toast تراجع 5 ثوانٍ · 1f طلب كارت قوة + بانر الأثر البرتقالي · 1g نهاية المباراة: ملخص → نجم المباراة → اعتماد مزدوج بـ PIN · 1h الكونسول عرضيًا 844×390.

**القسم 2 — الحيوية والتفاعل:** 2a الرئيسية النهائية (شريط لقطات + بطاقة مباشر بخطوط سرعة + «هدف الآن» عائم) — **هي المعتمدة بدل 1b** · 2b محادثة المباراة (استطلاع قبل + دردشة حية بوضع تهدئة 15ث + رسالة هدف نظامية ذهبية + قوالب ردود) · 2c الرسائل (إعلانات رسمية للقراءة، مجموعة فريق تلقائية، طلبات رسمية بحالات ملوّنة) · 2d الإعدادات (مفتاح لكل نوع إشعار) · 2e تجربة الزائر + ورقة «ادخل كمشجع» · 2f بطاقة اللاعب القابلة للجمع (تترقى بالإنجازات) · 2g التوقعات (± ستيبرز، ثقة ×2 مرة/ليلة، جائزة كارت) · 2h استوديو المشاركة (ستوري/مربع/واتساب) · 2i وضع TV للبروجيكتور.

**القسم 3 — التغطية الكاملة:** 3a المباريات حسب الليلة (اليوم المنطقي: ما بعد منتصف الليل يتبع ليلته) · 3b الترتيب الكامل + شجرة الكأس · 3c صفحة الفريق · 3d الإحصائيات (بطل القائمة مميز) · 3e المجتمع · 3f الدخول/كود الدعوة (بلا بريد إلكتروني؛ الاسترجاع عبر القائد/الأدمن) · 3g كروت القائد (متاح/مجدول/مستهلك) · 3h إرسال التشكيلة (الموقوف مقفول) · 3i اللاعبون والدعوات (كود بصلاحية واستخدامات) · 3j مهام الحكم/المسجّل + التحضير · **ديسكتوب:** 3k معالج 9 خطوات + حاسبة النظام · 3l القرعة التفاعلية · 3m مولد الجدول (3 سيناريوهات + معاينة ليالٍ + تعارضات) · 3n لوحة الأدمن · 3o الاعتماد/الانضباط/الإشراف · 3p إسناد الطاقم (تنبيه: حكم يلعب في نفس المباراة) + سجل التدقيق · 3q لوحة المنصة.

**القسم 4 — النواقص:** 4a إشعاراتي · 4b حسابي (عابر للدوريات) · 4c المسابقات + قاعة المشاهير · 4d تحرير الخط الزمني (سبب إلزامي → تدقيق) + **وضع أوفلاين بطابور مزامنة** · **4e محرر الجدول اليدوي** (سحب بين الليالي/داخلها بمقبض ⠿، تبديل، تثبيت 🔒، فحص حي للقيود، نشر دفعة واحدة؛ موبايل: تحديد مباراتين → تبديل) · **4f إدارة المباراة** (تأجيل باقتراح تلقائي / إلغاء بسبب / **انسحاب فريق: فوز الخصوم 3–0 + خصم نقطة، أو إلغاء بلا نقاط، أو شطب السجل** — مع معاينة الأثر) · 4g الملاعب والاستثناءات · 4h كتالوج الكروت والتوزيع · 4i فرق الأدمن (استيراد CSV، إعادة كلمات مرور، انتقالات).

**القسم 5 — الهوية:** 5a بوستر الجدول المولَّد تلقائيًا (قالب استوديو الجرافيك — HTML→صورة عبر @vercel/og) · 5b تدقيق الهوية على البوستر.

## Interactions & Behavior
- **ضغطتان لأي حدث** في الكونسول: حدث → لاعب → تم (الصانع/النوع اختياريان). تراجع 5 ثوانٍ. إنذار ثانٍ = طرد تلقائي. الدقيقة تلقائية وقابلة للتعديل.
- تعديل/حذف حدث يتطلب سببًا (chips جاهزة) ويُسجَّل في التدقيق.
- أوفلاين: الأحداث في IndexedDB (طابور ظاهر بالحالة)، مزامنة عند عودة الشبكة.
- كارت القوة: طلب القائد → نافذة قبول للحكم بمهلة عدّ تنازلي → بانر برتقالي حتى تحقق الأثر → استهلاك. النتيجة تُشتق من `value` الأحداث (هدف ×2 = value:2).
- الاعتماد المزدوج يقفل النتيجة → يحدّث الترتيب فورًا → منشور تلقائي → احتساب الإيقافات. إعادة الفتح للأدمن فقط وتُسجَّل.
- الأوراق السفلية (Bottom Sheets) بدل النوافذ المنبثقة على الموبايل، بخلفية معتمة `rgba(4,8,20,.55–.6)`.
- المباراة الحية: تحديث لحظي (Supabase Realtime)، عداد متابعين، تفاعلات إيموجي بتجميع.
- شريط التنقل السفلي: الرئيسية · المباريات · الترتيب · المجتمع · أنا (النشط ذهبي + رمز مملوء) — يظهر «مهامي» تلقائيًا للحكم أيام إسناده.
- محرر الجدول: التغييرات تتجمع «غير منشورة» ثم تُنشر معًا بإشعار للفرق وسجل تغييرات عام.
