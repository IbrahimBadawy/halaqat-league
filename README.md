# دوري الحلقات — Halaqat League Platform

منصة عربية (RTL) Mobile-first لإدارة ومتابعة «دوري الحلقات — صيف 2026»: متابعة المباريات
والترتيب لحظة بلحظة، شاشة تسجيل مباشر من الملعب، كروت قوة، ولوحة أدمن.

الهوية والشاشات مبنية طبقًا لعدة التصميم في [docs/design_handoff_halaqat_league](docs/design_handoff_halaqat_league)
والمواصفة الكاملة في [docs/league-platform-spec.md](docs/league-platform-spec.md).

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح <http://localhost:3000> — يفضَّل من الموبايل أو بمحاكاة عرض 390px.

- **بيانات الدوري الحقيقي** (10 فرق، مجموعتان، 24 مباراة، 4 ليالي جمعة) محمّلة تلقائيًا من
  `data/first-league.json`.
- من صفحة **«أنا»** بدّل دورك إلى *المسجّل* لفتح كونسول التسجيل، أو *الأدمن* للوحة الإدارة
  (رقم اعتماد النتائج الافتراضي: `1234`).
- زر **«تعبئة بيانات تجريبية»** في صفحة «أنا» يملأ ليلة 21/8 بنتائج ومباراة مباشرة للمعاينة.

## الصفحات

كل مباراة تظهر دائمًا بثلاثيتها: **اليوم (الليلة المنطقية) + الفترة + الملعب** — وقد تُلعب
مباراتان في نفس الفترة على ملعبين مختلفين وتظهران معًا بوضوح.

| للجمهور | للتشغيل |
|---|---|
| `/` الرئيسية (مباشر + مباريات الليلة) | `/match/{id}/console` كونسول التسجيل (ضغطتان لأي حدث) |
| `/matches` الليالي مجمعة بالفترة | `/officiate` مهام المسجّل |
| `/standings` الترتيب + شجرة الكأس | `/admin` لوحة الأدمن (اعتمادات، انضباط، تدقيق) |
| `/stats` الهدافون والشباك النظيفة والموقوفون | `/admin/schedule` **محرر الجدول**: تغيير اليوم/الفترة/الملعب لأي مباراة مع فحص تعارضات حي واقتراح أقرب فترة |
| `/predict` التوقعات (3 نقاط للنتيجة، 1 للاتجاه) | |
| `/community` المجتمع (نشر + إعجابات + نتائج تلقائية) | |
| `/cards` كروت القوة · `/rules` اللائحة | |
| `/tv` شاشة الملعب (بروجيكتور) · `/poster` بوستر الجدول الحي | |
| `/notifications` الإشعارات (أهداف، اعتمادات، تغيير مواعيد) | |

الإيقافات تلقائية: الطرد = مباراة، وإنذاران متراكمان = مباراة — الموقوف يُحظر من التشكيلة
والكونسول ويظهر في `/stats`.

## أين البيانات؟

المرحلة 0 تعمل **بدون سيرفر**: القراءة من ملف الـ seed، والأحداث والنتائج تُحفظ في
`localStorage` على الجهاز. كل المنطق الحسابي (اشتقاق النتيجة من الأحداث، الترتيب وكسر التعادل)
محركات نقية في `lib/` جاهزة للتوصيل بـ Supabase في المرحلة التالية — راجع `CLAUDE.md`.

## النشر على Vercel

المشروع Next.js قياسي: اربط المستودع بـ Vercel وسيُبنى وينشر تلقائيًا بلا أي متغيرات بيئة.
